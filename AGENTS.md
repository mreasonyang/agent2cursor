# agent2cursor

Use Node >=22.13. Run `npm run check` before delivery. SDK integration uses @grok/agent-sdk 0.3.0 in the ignored `.validation/` directory; never vendor SDK source or documentation.

Preserve every source frontmatter field in the migration report. Never silently expand a subagent's permissions. Generated script tools are disabled stubs until an operator implements the JSON contract. Conversion must never execute source scripts, overwrite existing output, traverse symlinks, or copy credential files.

Keep fixture validation, live model execution, remote deployment, and npm publication as separate evidence levels. Never claim shell access is read-only. No raw process argv, environment dumps, auth files, or unfiltered runtime logs in diagnostics. Use the user's safe-processes utility for process checks.
